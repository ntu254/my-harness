# v0.4 Plan

Date: 2026-07-19

## Goal

Add the first provider-adapter contract and a standard quality gate on top of
the v0.3 single-task runner.

## Version Slice

v0.4 is not a full Claude/Codex integration. It creates the stable adapter shape
that those integrations can plug into later.

## Scope

- Load versioned schema files from `state/schema/*.sql`.
- Add `002-adapters.sql`.
- Add `agent_adapter` registry state.
- Add `adapter register`, `adapter list`, and `adapter run`.
- Route adapter runs through the existing runner lifecycle.
- Store `adapter_id` and original prompt on `agent_run`.
- Add `harness check` as a standard quality gate.
- Document adapter and check workflows.

## Acceptance Gates

- Existing DB migrates from version 1 to version 2.
- Fresh temp DB applies schema versions 1 and 2.
- `harness check --include-active --strict-active` passes.
- Mock adapter registers successfully.
- Mock adapter run completes and records `adapter_id` plus prompt.
- Inactive adapter run is rejected before execution.
- `MH-007` records passing evidence.

## Deferred

- Real provider-specific Claude/Codex command presets.
- Prompt file rendering.
- Adapter capability discovery.
- Retry/backoff policy.
- Migration rollback.
