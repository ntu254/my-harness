# v0.10 Plan - Contract And Test Hardening

## Goal

Prepare `my-harness` for v1.0 by turning key controller behavior into
contracts and repeatable tests.

## Scope

- Add JSON schema contracts for public registry and command-output shapes.
- Add local CLI contract tests using a temporary `MY_HARNESS_DB`.
- Run those tests from the standard `harness check` baseline.
- Align README and manifest version with the verified capability surface.

## Non-Goals

- No real Codex or Claude provider conformance suite.
- No multi-agent orchestration.
- No installer or project-pack adoption command yet.
- No live browser automation.

## Acceptance Criteria

- `python -m unittest discover -s tests -p "test_*.py"` passes.
- `.\scripts\harness.ps1 check --include-active --strict-active` passes and
  includes CLI contract tests.
- Schemas parse with `python -m json.tool`.
- `harness/features.json` records v0.10 evidence.
- README no longer presents v0.6 as the latest capability surface.
