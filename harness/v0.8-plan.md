# v0.8 Plan: Alignment Release

## Why

The original development plan expected early versions to build skills/capability routing, spec/code/design quality slices, human gates, and benchmarks. v0.3-v0.7 delivered useful runner and adapter foundations, but the controller layer was still incomplete.

v0.8 closes that gap without removing v0.7.

## Scope

- Add `route` command for lane, workflow, skills, capabilities, proof policy, and human gate decisions.
- Add a machine-readable skill registry in `harness/skills.json`.
- Add tool capability seeding and registration.
- Add human approval gate records.
- Add route benchmark fixtures and `bench run`.
- Add persistence for route decisions, human gates, and benchmark runs.

## Out Of Scope

- Automatic real-agent selection.
- Learned scoring.
- Remote provider smoke tests.
- Full BRD/PRD document generation.
- UI/browser automation.

## Acceptance

- `harness route --json` returns workflow, skills, required capabilities, available tools, missing capabilities, proof policy, and human gate status.
- `harness tool seed` registers local/manual capabilities.
- `harness approval request` and `harness approval resolve` record human gates.
- `harness bench run --json --fail-on-regression` passes all v0.8 fixtures.
- `harness check --include-active` passes.
