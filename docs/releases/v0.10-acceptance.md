# v0.10 Acceptance

## Validated Behavior

v0.10 validates contract and regression-test hardening for the controller:

- UI route decisions block completion proof when browser, accessibility, and
  visual-review capabilities are unavailable.
- Scoped approvals validate matching scope and reject mismatched scope.
- Completion reports block stories without evidence and pass with fresh
  evidence.
- Benchmark runs still report scores and fail on regressions.
- Standard `harness check` runs the CLI contract suite.

## Commands

```powershell
python -m unittest discover -s tests -p "test_*.py"
.\scripts\harness.ps1 check --include-active --strict-active
python -m json.tool harness\features.json
python -m json.tool schemas\skill.schema.json
python -m json.tool schemas\benchmark.schema.json
python -m json.tool schemas\route-decision.schema.json
python -m json.tool schemas\final-report.schema.json
```

## Result

- `python -m unittest discover -s tests -p "test_*.py"` passed 4 tests.
- `.\scripts\harness.ps1 check --include-active --strict-active` passed with
  CLI contract tests included.
- Schema and registry JSON parsing passed.

## Residual Risk

- Schemas are currently parsed, not validated with a full JSON Schema engine.
- Contract tests cover core controller paths, not every CLI command.
- Provider adapters remain deferred until after v1.0 readiness hardening.
