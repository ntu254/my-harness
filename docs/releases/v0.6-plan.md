# v0.6 Plan

Date: 2026-07-19

## Goal

Reduce shell risk in adapter execution and add prompt template files.

## Version Slice

v0.6 improves the adapter execution contract. It does not yet perform real
Codex or Claude provider smoke, because those commands require local provider
availability and user-approved command templates.

## Scope

- Add `004-argv-and-prompt-templates.sql`.
- Add `command_mode` and `command_argv_json` to adapter and run state.
- Support adapter `argv` execution with `shell=False`.
- Keep shell mode for compatibility.
- Add `adapter run --prompt-template`.
- Add repeated `--var key=value` prompt-template variables.
- Add `templates/prompts/adapter-smoke.md`.
- Update adapter presets to prefer argv mode.

## Acceptance Gates

- Existing DB migrates to schema version 4.
- Fresh temp DB applies schema versions 1, 2, 3, and 4.
- `mock-python` preset installs with `command_mode=argv`.
- `adapter run --adapter mock-python --id MH-009 ...` completes with argv mode.
- `adapter run --prompt-template ...` completes with rendered prompt.
- Run records store `command_mode=argv` and rendered `command_argv_json`.
- `harness check --include-active --strict-active` passes.

## Deferred

- Real Codex provider smoke.
- Real Claude provider smoke.
- Full prompt-template include system.
- Shell-free verification commands.
