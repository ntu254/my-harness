# Clean-State Checklist

Before ending a significant session:

- [ ] The standard startup path still works, or failure is recorded.
- [ ] The standard verification path ran, or skip reason is recorded.
- [ ] Current progress is recorded in `harness/progress.md`.
- [ ] Feature statuses match actual evidence in `harness/features.json`.
- [ ] No unfinished step is hidden.
- [ ] The next session can continue without chat history.
- [ ] Human-gated actions were not executed without explicit approval.
