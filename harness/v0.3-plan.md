# v0.3 Plan

Date: 2026-07-19

## Goal

Build the first orchestration layer on top of the v0.2 SQLite state spine.

## Version Slice

v0.3 is not a daemon, UI, queue, or multi-agent scheduler. It is a local
single-task runner that proves the harness can surround command execution with
classification, durable state, evidence, verification, and handoff.

## Scope

- Add an `agent_run` state table.
- Add `harness run once`.
- Classify lane automatically from work type, scope, uncertainty,
  reversibility, and risk.
- Execute normal/tiny task commands.
- Require explicit `--allow-high-risk` for high-risk or approval-required
  execution.
- Capture agent and verification command logs.
- Record evidence and trace rows.
- Update story status to `completed`, `failed`, or `needs_human`.

## Acceptance Gates

- Startup initializes the updated schema.
- CLI syntax compiles.
- Normal runner smoke creates intake/story/run/evidence/trace records.
- Normal runner smoke completes when agent and verify commands pass.
- Guarded high-risk smoke records `needs_human` and does not execute command.
- Runtime logs are ignored by git.
- `MH-006` records passing evidence.

## Deferred

- Long-running daemon or queue.
- Parallel multi-agent dispatch.
- Provider-specific Claude/Codex adapters.
- Full migration framework.
- Normalized many-to-many evidence/story relations.
- Rich retry policy.
