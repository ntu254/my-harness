# v0.7 Plan: Provider Smoke Gates, Capability Taxonomy, and Shell-Free Verification

## Goals

1. Provider smoke gates: validate real Codex and Claude adapters end to end when available.
2. Adapter capability taxonomy: define what capabilities each adapter provides.
3. Shell-free verification: make verification commands runnable without shell execution.

## Scope

This release focuses on:

- adding capability declarations to adapter registry
- implementing an `adapter capability` command
- adding shell-free verification command execution via argv mode
- smoke testing Claude and Codex adapters if available
- documenting provider-specific adapter limits and features

## Design

### 1. Adapter Capability Schema

Draft fields for `agent_adapter`:

- `capabilities_json`: JSON array of strings
- `max_prompt_length`: integer provider limit
- `supports_raw_prompt`: boolean
- `supports_templates`: boolean
- `supports_argv`: boolean
- `verification_mode`: `shell`, `argv`, or `native`

### 2. Capability Resolver

Planned command:

```text
harness adapter capability --adapter <id>
```

It should return capabilities, limits, modes, trust level, and availability.

### 3. Shell-Free Verification

Add verification mode support:

- `shell`: current behavior
- `argv`: shell-free verification command
- `native`: provider-native verification if available

### 4. Provider Smoke Tests

Potential tasks:

- `MH-010`: Claude adapter smoke if CLI is available
- `MH-011`: Codex adapter smoke if CLI is available
- `MH-012`: capability discovery and routing

## Acceptance Criteria

- `adapter capability --adapter mock-python` returns capabilities.
- `adapter run` can enforce or warn on missing required capabilities.
- Verification can run in argv mode without shell parsing.
- Existing v0.1-v0.6 features remain passing.
- Claude and Codex presets are discovered and smoke-tested if available.

## Risks

- Provider CLI flags may differ from preset assumptions.
- Prompt length limits may require truncation logic.
- Argv rendering may not handle all template edge cases.
