# v0.5 Plan

Date: 2026-07-19

## Goal

Make the adapter contract more practical by adding provider presets, prompt
file rendering, local discovery, and safer template placeholders.

## Version Slice

v0.5 still does not claim complete Claude or Codex automation. It prepares the
contract so each provider can be enabled per machine after discovery and smoke
validation.

## Scope

- Add `003-adapter-discovery.sql`.
- Add adapter preset installation for `mock-python`, `codex-local`, and
  `claude-local`.
- Add `adapter discover`.
- Add `adapter run --prompt-file`.
- Write runtime prompt files when `--prompt` is used.
- Add shell-quoted placeholders such as `{prompt_shell}` and
  `{prompt_file_shell}`.
- Reject raw `{prompt}` templates by default.

## Acceptance Gates

- Existing DB migrates to schema version 3.
- Fresh temp DB applies schema versions 1, 2, and 3.
- `adapter preset all` installs all built-in presets.
- `adapter discover --adapter mock-python` marks it present on this machine.
- `adapter run --adapter mock-python --id MH-008 --prompt ...` completes.
- The prompt runtime file is generated and ignored by git.
- `adapter run --prompt-file ...` completes.
- Raw `{prompt}` template is rejected by default.
- `harness check --include-active --strict-active` passes.

## Deferred

- Real provider smoke for Codex and Claude.
- Provider-specific retry policies.
- Prompt templating with includes and variables.
- Structured adapter capability taxonomy.
- Shell-free subprocess argument arrays.
