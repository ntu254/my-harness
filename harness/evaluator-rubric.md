# Evaluator Rubric

Use this before accepting meaningful work.

| Category | Question | Score |
| --- | --- | ---: |
| Correctness | Does the implementation match the requested behavior? | 0-2 |
| Verification | Did required checks actually run with evidence? | 0-2 |
| Scope discipline | Did the session remain within selected scope? | 0-2 |
| Reliability | Does the result survive restart or rerun? | 0-2 |
| Maintainability | Can the next session understand the code and docs? | 0-2 |
| Handoff readiness | Can a new session continue from repository artifacts alone? | 0-2 |

Conclusions:

- Accept
- Revise
- Block

Low scores should produce a repair task, blocker, or friction note.
